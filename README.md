# Tortho-Gaussian++

An advanced 3DGS training framework that suppresses geometric drift and floaters in UAV scenes and automatically prunes unreliable peripheral regions, coupled with a robust gravity-aligned TDOM rendering solution.

Project Page: [Project website](https://iris-lab-whu.github.io/Tortho-Gaussian-PlusPlus/)

arXiv: [arXiv:2611.33905](https://arxiv.org/abs/2611.33905)

## At Firrrrrrrrrst: A tiny change for amazing results.

## Data and Preparation

In the data preparation step, we utilize the `convert.py` script to invoke COLMAP for structure-from-motion (SfM) reconstruction, producing a sparse 3D point cloud of the scene.

Place the original images in an `input/` subdirectory:

```text
your_image_path/
└── input/
    ├── image_0001.jpg
    ├── image_0002.jpg
    └── ...
```

With the COLMAP available on `PATH`, run from `Tortho-Gaussian++train/`:

```bash
python convert.py -s {your_image_path}
```
## Environment

Training and rendering use separate environments. Install each rasterizer only in its matching environment.

The environment files use Python 3.8.20, PyTorch 2.0.1, torchvision 0.15.2, CUDA runtime 11.8, and NumPy 1.24.4. Building the extensions also requires an NVIDIA GPU, the CUDA 11.8 toolkit (`nvcc`), and a compatible C++ compiler. The Conda CUDA runtime does not supply `nvcc`; configure `CUDA_HOME` and `PATH` for your toolkit before running `install.sh`.
Run each installation block from the repository root.

Create the training environment:

```bash
cd Tortho-Gaussian++train
conda env create -f environment.yml
conda activate TGPP-train
bash install.sh
```

Then create the rendering environment:

```bash
cd Tortho-Gaussian++render
conda env create -f environment.yml
conda activate TGPP-render
bash install.sh
```
The rendering setup automatically downloads PerspectiveFields, which will be used in our TDOM rendering; its model weights download automatically on first use.
## Training

Activate `TGPP-train` and run from `Tortho-Gaussian++train/`. Use absolute scene and model paths so the same model can be accessed from the rendering directory:

```bash
python train.py \
    -s /absolute/path/to/scene \
    -m /absolute/path/to/model \
    --inherit_parent_adam_state \
    --enable_weak_support \
    --data_device cpu
```
## Render

Activate `TGPP-render` and run from `Tortho-Gaussian++render/`:

```bash
conda activate TGPP-render
python render_dummy.py \
    -m /absolute/path/to/model \
    -s /absolute/path/to/scene
```

If you want to visualize geometric support scores, add `--visualize_support_score`:

```bash
python render_dummy.py \
    -m /absolute/path/to/model \
    -s /absolute/path/to/scene \
    --visualize_support_score
```
This renders `point_cloud/iteration_<N>/point_cloud_weak_support.ply`, generated by training with `--enable_weak_support`.
## Prune

Additionally, optional post-training pruning is available after rendering. Run from `Tortho-Gaussian++train/`:

```bash
conda activate TGPP-train
python train.py \
    -m /absolute/path/to/model \
    --postprocess_support_prune_mask_thresh 0.1
```

Pruning writes a separate `point_cloud/iteration_<N>/support_prune_mask_0.1/` folder containing the pruned `point_cloud.ply` and its matching `weak_support.npz`. The original point cloud and support records are preserved.
